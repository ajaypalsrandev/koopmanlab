# Evaluating the saved MLP

Run from the repository root with the project environment activated:

```bash
python scripts/evaluate_mlp.py
```

The default checkpoint is `results/mlp/small_angle/seed_42/best_model.pt`.
To evaluate another trained checkpoint or choose an output directory:

```bash
python scripts/evaluate_mlp.py --checkpoint /path/to/best_model.pt --output-dir /path/to/output
```

The script reads the dataset settings from the checkpoint and recreates the
training/validation/test split. It fits DMD and EDMD on the training split and
scores all three models on the same validation trajectories. It does not train
the MLP or evaluate the test split. A missing dataset seed is an error: regenerate
older checkpoints with `seed` explicitly recorded in the training configuration.

The MLP uses its saved training normalization statistics. Predictions are
converted to physical units before scoring. One-step prediction receives true
states; recursive prediction receives only the initial state. That supplied
initial state is excluded from rollout scoring.

## Saved outputs

By default, results are under `docs/benchmarks/mlp/checkpoint_<hash>/`. The hash
identifies the checkpoint contents, so a new trained checkpoint gets a separate
folder. Re-evaluating the identical checkpoint replaces its evaluation outputs.

- `comparison.json`: configuration, split sizes, checkpoint identity, selection
  indices, and scores for all three models.
- `dmd/metrics.json`, `edmd/metrics.json`, `mlp/metrics.json`: model-specific
  scores, per-trajectory errors, and mean error curves.
- Each model folder also contains `predictions.npz`, with times, true states,
  one-step predictions, and full recursive rollouts. These archives are ignored
  by Git and can be regenerated by running the evaluator.
- `representative.png` and `worst.png`: all three models on the same trajectories,
  selected by EDMD rollout error. They are not necessarily the MLP's median or
  worst examples. Titles and comparison metadata record the selection basis.
- `error_by_time.png`: mean one-step and rollout errors over validation data.
- `training_history.png`: normalized training/validation loss, with the selected
  epoch marked.

Training loss is normalized; benchmark errors are in physical units. Aggregate
state MSE combines angle and angular-velocity squared errors without rescaling,
so separate state errors are reported as well. The MLP has no single learned
transition matrix, and no matrix spectral radius is reported for it.

The current five-epoch small-angle checkpoint is a workflow check, not a finished
MLP benchmark. Evaluate longer training and additional seeds before drawing
broader conclusions. Checkpoint files under `results/` are local and ignored;
run `python scripts/train_mlp.py` to create the default checkpoint after cloning.
